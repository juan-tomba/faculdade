-  A interação é realizada por meio de uma *interface*
## **Processo de interação**

- Usuário -> interface -> objetivo -> contexto
- Exemplo:
	- Professor -> Powerpoint -> criar, visualizar, apresentar -> (imagens de referencia)
- *Todos os elementos afetam o processo de interação*

## Perspectivas de Interação Humano-Computador

### *Usuário como computador*

- Forma restrita de entrada de dados- apenas **aquilo que o computador entende**
- Exemplos: Terminal, formulários

### *Parceiro de discurso*

- O sistema imita o comportamento humano
- Exemplo: chatbots, assistentes digitais

## Usabilidade

- Definido por:
	- **Facilidade de aprendizado**
	- **Facilidade de recordação**
	- **Eficiencia**
	- **Segurança no uso**
	- **Satisfação**
